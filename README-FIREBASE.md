# রঙিন দুনিয়া — ফায়ারবেইজ সেটআপ গাইড

এই সাইট এখন তোমার ফায়ারবেইজ প্রজেক্ট (`baby-blog-d41a2`) এর সাথে সরাসরি
সংযুক্ত — Firestore Database এ লেখা/মেনু/কমেন্ট থাকবে, আর Storage এ ছবি/ভিডিও/পিডিএফ।

## ১) ফায়ারবেইজ কনসোলে যা চালু করতে হবে

1. https://console.firebase.google.com এ গিয়ে `baby-blog-d41a2` প্রজেক্ট খোলো।
2. বাম মেনু থেকে **Build → Firestore Database → Create database** — সহজে শুরু করতে
   "Start in test mode" বেছে নাও (৩০ দিন খোলা থাকবে, পরে নিয়ম বদলাতে হবে)।
3. **Build → Storage → Get started** — এটাও test mode এ শুরু করো।
4. দুই জায়গাতেই "Rules" ট্যাবে গিয়ে নিশ্চিত করো নিয়মটা এমন আছে (টেস্টিং এর জন্য):
   ```
   allow read, write: if true;
   ```
   ⚠️ এটি সাময়িক — সাইট মানুষের কাছে ছাড়ার আগে Authentication যোগ করে
   শুধু তোমার অ্যাডমিন লগইনকে লেখার অনুমতি দেওয়া উচিত, নাহলে যে কেউ ডেটা
   মুছে ফেলতে পারবে।

## ২) সাইটটি কীভাবে চালাবে (file:// দিয়ে ডাবল-ক্লিক করলে কাজ করবে না)

ব্রাউজার নিরাপত্তার কারণে ES Module (যা Firebase ব্যবহার করে) সরাসরি
`file://` থেকে চলে না। যেকোনো একটি উপায়ে লোকাল সার্ভার চালাও:

- **Python থাকলে:** ফোল্ডারে গিয়ে টার্মিনালে লেখো:
  `python3 -m http.server 8000` — তারপর ব্রাউজারে খোলো `http://localhost:8000`
- **Node.js থাকলে:** `npx serve .` — তারপর দেখানো লিংকে যাও
- **VS Code ব্যবহার করলে:** "Live Server" এক্সটেনশন ইনস্টল করে `index.html`
  এ রাইট-ক্লিক করে "Open with Live Server"
- **সরাসরি লাইভ করতে চাইলে:** Firebase Hosting এ ডিপ্লয় করো (`firebase deploy`),
  তখন যেকোনো ডিভাইস থেকে লিংকে ঢুকলেই কাজ করবে।

## ৩) প্রথমবার চালানোর সময়

`index.html` প্রথমবার খুললে সাইট নিজে থেকেই Firestore-এ ১০টি বিভাগ, মেনু,
সেটিংস আর ৫০টি ডেমো গল্প/লেখা বসিয়ে দেবে (আগে যা লোকাল স্টোরেজে ছিল, এখন
সবার জন্য শেয়ার্ড ডেটা)। দ্বিতীয়বার থেকে আর সিড হবে না।

## ৪) অ্যাডমিন প্যানেল থেকে কনটেন্ট বদলানো

- `admin.html` থেকে পোস্ট লেখা/সম্পাদনা, ছবি-ভিডিও-পিডিএফ আপলোড, মেনু-পেইজ
  ব্যবস্থাপনা — সবই এখন সরাসরি Firestore/Storage এ সেভ হবে।
- ডেমো ৫০টি গল্প মুছে নিজের লেখা বসাতে চাইলে, পোস্ট তালিকা থেকে 🗑️ বাটনে
  চেপে মুছে ফেলো, তারপর "➕ নতুন পোস্ট" দিয়ে নিজের লেখা যোগ করো।

## কোনো সমস্যা হলে

ব্রাউজারের Developer Console (F12) খুলে Console ট্যাবে লাল রঙের এরর মেসেজ
দেখো — সাধারণত Firestore/Storage Rules বন্ধ থাকলে "permission-denied" এর
মতো এরর দেখাবে, তখন ধাপ ১ আবার চেক করো।
